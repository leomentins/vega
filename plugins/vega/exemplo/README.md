# Projeto de exemplo

Um projeto de mentira, conduzido de ponta a ponta pela suíte do plugin
(`scripts/conducao/__tests__/exemplo.test.mjs`): a declaração do projeto à
fábrica em `.vega/declaracao.json`, com o adaptador em `conducao`, o plano no formato público em
`docs/planos/` e a página do projeto em `docs/conducao.md`.
